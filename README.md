# Дримворлд Навсегда — лаунчер

Лаунчер для сервера **Дримворлд Навсегда** (WoW Forever, TrinityCore forever).

Репозиторий основан на открытом launcher из проекта
[`jibay442/forever_docker`](https://github.com/jibay442/forever_docker) (GPL-2.0).
Он устанавливает и обновляет клиент, выполняет вход через LoginREST bnetserver,
подставляет ключ сервера и запускает `Wow.exe`.

## Что делает

1. Находит клиент или устанавливает его в папку рядом с лаунчером.
2. Обновляет клиент по манифесту и проверяет SHA-256.
3. Логинится на `https://trinity.actual.mmolabs.ru:8081` по email и паролю.
4. Запоминает сессию на 30 дней.
5. Подставляет ключ сервера в память клиента и запускает игру.

Кнопка запуска имеет три состояния: **Играть** (клиент готов),
**Обновить** (клиент устарел) и **Установить** (клиента нет).

## Сборка

GitHub Actions, Windows only: `.github/workflows/launcher.yml`.
Результат — `Forever AI.exe` и NSIS-установщик.

Локально (Windows):

```powershell
cd app
npm install -g @tauri-apps/cli@2
npx @tauri-apps/cli@2 build --bundles nsis
```

## Настройки

По умолчанию:

- адрес: `92.42.44.9`
- портал: `trinity.actual.mmolabs.ru`
- сайт/новости: `https://forever.mmolabs.ru/launcher`
- мир: `Дримворлд Навсегда`

Эти параметры фиксированы в сборке.

## Сертификат

Портал использует публичный сертификат Let's Encrypt; отдельная установка CA
и правка `hosts` не требуются.

## Обновление клиента

Лаунчер проверяет `https://forever.mmolabs.ru/launcher/manifest.json`,
скачивает недостающие/изменённые файлы, проверяет SHA-256 и атомарно заменяет
их. Клиентские данные раздаются нашим сервером; Blizzard CDN для игроков не
используется. Аддоны в лаунчер не входят — игроки ставят их самостоятельно.

## Автообновление лаунчера

При запуске лаунчер читает `launcher_manifest.json` с сайта сервера. Если там
версия новее, появляется баннер «Доступно обновление лаунчера». По кнопке
лаунчер скачивает новый EXE, проверяет размер и SHA-256, запускает helper,
выходит, заменяет свой файл и перезапускается. Пароль и настройки при этом не
теряются.

Автообновление работает в Windows-версии. Первый переход на версию с
автообновлением (1.1.2) нужно один раз выполнить вручную: в более старых
версиях этого кода ещё нет.

## Проверка готовности ПК

Проверки в настройках оставлены для диагностики. Для рабочего портала
`trinity.actual.mmolabs.ru` hosts и приватный CA не нужны.

## Сервер

Лаунчер работает только с нашим сервером; адрес, портал и сайт не редактируются.
Портал — `trinity.actual.mmolabs.ru`, сертификат Let's Encrypt проверяется
системным хранилищем.

## Патч портала

`Wow.exe` патчится **на сервере**: `scripts/patch-client-portal.py` заменяет
18-байтовый суффикс `.actual.battle.net` на `.actual.<домен>` после каждого
обновления клиента. Лаунчер получает уже готовый файл через манифест.

Для `Wow.exe` в манифесте стоит `verify_sha256: true`: размер патченного файла
не меняется, поэтому лаунчер дополнительно сверяет SHA-256 и скачивает новую
версию, даже если размер совпадает. Игрок не заменяет файлы вручную.

## Установка клиента с нуля

В «Настройки → Игра» выберите пустую папку (корень установки, не `_forever_`)
и нажмите «Скачать клиент». Лаунчер скачает все файлы из манифеста (~54 ГБ),
проверит SHA-256, создаст `_forever_` и `Data`, после чего сам переключит
`game_dir` на `_forever_/Wow.exe`. Если часть клиента уже есть, скачаются
только отсутствующие/несовпавшие файлы.
