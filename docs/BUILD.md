# Сборка лаунчера

## Локальная сборка MinGW (Linux → Windows)

Для автономного EXE нужно встроить официальный `WebView2Loader.dll`
из x64-каталога зависимости `webview2-com-sys`. Без этого обычная GNU-сборка
создаёт EXE с внешней DLL, который нельзя публиковать как одиночный файл.

```bash
FOREVER_WEBVIEW2_LOADER=/path/to/webview2-com-sys/x64/WebView2Loader.dll \
TMPDIR=/var/tmp cargo build --release --target x86_64-pc-windows-gnu
```

Перед публикацией проверить `objdump -p ...exe`: среди импортов не должно
быть `WebView2Loader.dll` или DLL самого лаунчера. MSVC-сборки используют
штатный статический загрузчик и не требуют этой переменной.

## Ревизии клиента

С версии 1.4.11 поле `data_revision` заставляет обновлять весь набор
даже при том же `build`. Сначала загрузка и SHA-256 в служебной папке,
затем замена Data целиком, и только после успеха запись маркера ревизии.
Индексы входят в снимок; WTF и аддоны остаются пользовательскими.

С версии 1.4.13 после установки ревизии имена и содержимое `.idx` во всех
хранилищах `Data/**` вообще не проверяются: игра меняет поколения индексов.
Отсутствующий архив или конфиг Data требует восстановления полного снимка,
а не докачки отдельного файла поверх локальной раскладки.
Кнопка полной проверки предупреждает о загрузке всего комплекта и требуемом
дополнительном месте, продолжение требует подтверждения.

## GitHub Actions

Workflow: `.github/workflows/launcher.yml` (Windows only).

1. Запушьте репозиторий в `https://github.com/amatol/wowforever-launcher`.
2. Откройте **Actions → Launcher → Run workflow**.
3. Укажите версию, например `1.0.0`, и запустите.
4. Через ~10–15 минут появится релиз `v1.0.0` с NSIS-установщиком.

Публичный CA уже лежит в `app/src-tauri/resources/forever_root_ca.crt`.
Переменные репозитория не обязательны: адрес, мир и сайт заданы по умолчанию
в `app/src-tauri/src/config.rs`.

## Локальная сборка (Windows)

```powershell
cd app
npx --yes @tauri-apps/cli@2 build --bundles nsis
```

Требуется Rust stable, Node.js 22 и WebView2 (в Windows 10/11 есть).

## Проверка

- `cargo test --lib` в `app/src-tauri`.
- Установить лаунчер на чистую Windows, выбрать `_forever_` с `Wow.exe`.
- Нажать «Подготовить ПК», войти аккаунтом из бота, нажать «Играть».
- Проверить `hosts`, «Доверенные корневые сертификаты», вход в мир.
