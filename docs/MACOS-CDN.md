  проводился. Полный `.app` не собран и не запущен.

## Что нужно для обновления

Для чистой установки нужен согласованный комплект `.app`, включая
`Info.plist`, библиотеки и ресурсы, а не только исполняемый файл.
Проверить выдачу остальных объектов через архивные индексы CASC или
получить полный пакет той же сборки из Battle.net для подготовки релиза.
Идентификатор сборки закреплять в нашем манифесте, не брать автоматически
«последний» `wowf`: приложение и `Data` должны быть одной сборки.
Установка пакета и данных из Яндекс Диска должна проверяться на реальном
Mac, включая чистый запуск и обновление существующего клиента.

Прямая загрузка `.app` из Blizzard CDN — отдельный вариант для macOS,
не включённый в действующий режим раздачи. Если сохраняется требование
Yandex-only, проверенный пакет можно готовить из CDN/Battle.net при сборке
релиза, а игрокам отдавать с Яндекс Диска.
