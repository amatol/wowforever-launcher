# Yandex Disk как источник клиента (заготовка)

Статус: **код подготовлен, но в живой раздаче не включён.** Живой
`client_build.json` не содержит блока `yandex`, поэтому текущие игроки
продолжают работать по схеме 1.4.20 и ничего не скачивают из Yandex.

## Что уже реализовано

- В `client_build.json` можно добавить необязательный блок:

```json
"yandex": {
  "enabled": true,
  "public_url": "https://disk.yandex.ru/d/DxjZXLCwnEimiw",
  "path": "/1.60.1.70938"
}
```

- Для каждого файла, у которого есть `sha256` в `manifest.json`, лаунчер
  строит стабильный URL публичного API Yandex:

```
https://cloud-api.yandex.net/v1/disk/public/resources/download
  ?public_key=<публичная ссылка>&path=<папка версии>/<путь файла>
```

- API возвращает временный `href`; лаунчер разрешает его непосредственно
  перед скачиванием. В манифесте временные ссылки не хранятся.
- Для тяжёлых `Data/data/data.*` порядок источников: **Yandex Disk
  (3 попытки)**; без fallback на наш сервер. CDN Blizzard и сервер больше не
  используются для этих файлов.
- Для файлов из `overlay` (`_forever_/wow_loader.dll`, `Wow.exe`, `.build.info`,
  `Data/wowf`, `Data/ecache`, `Data/config`, `Data/indices`) источник — наш
  сервер.
- Проверка размера и SHA-256 остаётся обязательной.

## Что нужно для реального включения

1. Обновить сервер под нужную сборку (сервер уже принимает 70888 и 70938).
2. Сгенерировать `manifest.json` с корректными SHA-256 для новой версии.
   Yandex API отдаёт размер и MD5, но не SHA-256; хеши считаются один раз
   на сервере при подготовке релиза.
3. Добавить блок `yandex` в `client_build.json` и опубликовать новый
   манифест.
4. Для первого перехода используется **полная загрузка 70938**; diff-карта
   будет отдельным этапом.
5. Проверить полную установку и обновление на SteamOS и Windows.

## Ограничения

- Yandex Disk — не CDN; возможны лимиты API, скорости и массовых загрузок.
- Публичная ссылка должна быть стабильной; при её смене нужен новый
  `client_build.json`.
- Манифест и SHA-256 должны оставаться на нашей стороне, иначе публичную
  папку можно подменить.
